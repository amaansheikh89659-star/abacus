# Abacus Mastery

## Project Overview
Abacus Mastery is an educational application designed for students in grades 1 to 4 to learn and practice arithmetic using an interactive abacus interface. The application provides a hands-on approach to understanding place value, addition, subtraction, and more complex arithmetic concepts.

## Project Structure
The project consists of the following files:

- **index.html**: Contains the HTML structure of the application, including headers, navigation tabs, and the abacus frame. It links to the external CSS file for styling and the JavaScript file for functionality.
  
- **styles.css**: Contains the CSS styles that define the appearance of the application. It includes styles for the body, header, tabs, panels, buttons, and the abacus components, ensuring a consistent design.

- **script.js**: Implements the functionality of the abacus mastery application. It manages the abacus state, handles user interactions, renders the curriculum content, and manages the learning and practice modes.

## Setup Instructions
1. **Clone the Repository**: 
   ```
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory**:
   ```
   cd abacus-mastery
   ```

3. **Open the `index.html` File**: Open the `index.html` file in your web browser to view the application.

## Features
- Interactive abacus for visualizing arithmetic operations.
- Curriculum tailored for grades 1 to 4, covering basic to advanced arithmetic concepts.
- Modes for learning, practicing, and speed drills to enhance proficiency.

## Usage
- Use the navigation tabs to select the grade level and mode of learning.
- Follow the prompts to interact with the abacus and solve problems.
- Track your progress and accuracy through the provided feedback system.
